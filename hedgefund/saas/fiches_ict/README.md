# Fiches ICT du Mentor

Chaque fichier `NN-sujet.md` est une **fiche** de référence sur ICT. Le Mentor IA de l'espace de
trading (`/app/mentor/`) les cherche avec les définitions du moteur et les cours de l'académie,
répond à partir des passages trouvés et affiche les sources sous chaque réponse.

## Corriger ou enrichir le Mentor

1. Modifiez une fiche, ou créez-en une nouvelle (`15-mon-sujet.md`). La première ligne est le
   titre : `# Mon sujet`.
2. Écrivez comme pour un élève : définition, comment le repérer, comment l'utiliser, erreurs
   fréquentes, exemple chiffré (fictif, présenté comme un exemple).
3. Redémarrez la plateforme, ou cliquez sur **Réindexer** dans `/admin/` → SaaS IA → Base de
   connaissances du Mentor. La nouvelle version sert dès la question suivante.

Conseils :

- Une fiche = un sujet. La recherche se fait sur les mots : reprenez les termes que les membres
  emploient (« FVG », « fair value gap », « déséquilibre »).
- Si les enseignements d'ICT ont changé selon les années (2016-2017, 2022, 2024…), écrivez-le.
  Le Mentor le répétera au lieu de trancher au hasard.
- Quand la plateforme applique une règle chiffrée (taille minimale d'un FVG, seuils premium /
  discount…), elle vient des définitions du moteur (skill `ict-definitions`) : une section
  « Dans la plateforme » le rappelle, pour que le Mentor explique la même chose que l'Analyste.
- Le Mentor ne cite que des chiffres présents dans les passages trouvés (contrôle automatique) :
  un horaire ou un pourcentage absent des fiches ne sera pas affiché.
- Ne mettez ici **rien de confidentiel** : le dépôt peut être public et le Mentor cite les
  passages. Les stratégies réservées (6-7 Range, Swing Victorious) restent dans les cours vidéo.
- Dans `/admin/` → **SaaS IA** → **Questions posées au Mentor**, les questions « hors des
  contenus », et celles que l'IA a jugées « partielles », montrent ce qu'il manque : c'est la
  meilleure liste de fiches à écrire.

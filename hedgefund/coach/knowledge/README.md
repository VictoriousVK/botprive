# Base de connaissances du Coach IA

Chaque fichier `NN-sujet.md` est une **fiche** que le coach lit avant chaque réponse. Il doit
s'appuyer dessus en priorité et citer les fiches utilisées (« Sources » sous chaque réponse).

## Corriger ou enrichir le coach

1. Modifiez une fiche, ou créez-en une nouvelle (`15-mon-sujet.md`). La première ligne est le
   titre : `# Mon sujet`.
2. Écrivez comme pour un élève : définition, comment le repérer, comment l'utiliser, erreurs
   fréquentes, exemple chiffré.
3. Redémarrez la plateforme. Le coach utilise la nouvelle version dès la question suivante.

Conseils :

- Une fiche = un sujet. Le nom du fichier sert d'identifiant dans les sources affichées.
- Si les enseignements d'ICT ont changé selon les années (2016-2017, 2022, 2024…), écrivez-le.
  Le coach le répétera au lieu de trancher au hasard.
- Ne mettez ici **rien de confidentiel** : le dépôt peut être public et les membres peuvent
  demander au coach de citer une fiche. Les stratégies réservées (6-7 Range, Swing Victorious)
  restent dans les cours vidéo, pas ici.
- Taille : toute la base est envoyée à chaque question (avec mise en cache). Au-delà d'environ
  150 000 caractères au total, le coût par question augmente nettement.
- Dans `/admin/` → **Coach IA**, la liste des questions marquées « hors base » montre ce qu'il
  manque. C'est la meilleure liste de fiches à écrire.

# Affiches du Live Club

Dépose ici tes affiches (JPG, PNG ou WebP, 5 Mo maximum chacune). Elles apparaissent automatiquement
sur la page d'accueil, dans l'ordre alphabétique des noms de fichiers.

Conseils de nommage : `01-live-club-violet.jpg`, `02-live-club-or.jpg`, etc. Le nom sert de texte
alternatif (accessibilité) : « 01-live-club-violet » devient « Live club violet ».

Pour les ajouter sans ligne de commande : sur GitHub, ouvre ce dossier → **Add file → Upload files**,
puis valide le commit.
